# Coffe-Pack_Clone_1_2025 (In Development)

## 🎮 Genre: 3D, Casual, Puzzle

### 🔹 Current Features:

- **Dynamic Difficulty System** – Randomly assigns items to the player based on the current puzzle level and game state, ensuring a balanced challenge.
- **Level Editor** – Create custom puzzle quests for specific levels, with the ability to predefine level maps by importing CSV files.
- **Drag & Drop System** – Fully supports both mouse interactions (PC) and touch controls (Mobile) for seamless gameplay.
- **State Pattern Implementation** – Uses a structured state management system to handle different game states efficiently, improving scalability and maintainability.
- **Level Selection** – Allows players to choose levels from a structured menu, unlocking new levels as they progress.
